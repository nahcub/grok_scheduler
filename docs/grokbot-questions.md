# 그록봇 능력 확인 질문지

2026-11-01에 그록봇에게 붙여넣은 질문이다. 그록봇의 답변 정리는 [grokbot-research.md](grokbot-research.md) 7절에 있다. 새 봇이나 바뀐 환경에서 다시 확인할 때 그대로 재사용한다.

```text
너(그록봇)를 위한 작업 시간 예측 도구를 만들려고 해. 어떤 형태로 만들지 정하려고 하니 아래 질문에 답해 줘.

답변 규칙:
- 직접 해 볼 수 있는 건 실제로 해 보고 결과(명령 출력, 화면 내용)를 같이 보여 줘.
- 답마다 [확인함] / [추정] / [모름] 중 하나를 붙여 줘. 확실하지 않으면 [모름]이라고 해 줘.
- 질문 번호를 맞춰서 짧게 답해 줘.

## A. 네 컴퓨터(VM) 환경
1. 운영체제와 버전이 뭐야?
2. 터미널을 열고 명령을 실행할 수 있어? 된다면 `echo hello`를 실행해서 결과를 보여 줘.
3. Python과 Node.js가 설치돼 있어? `python3 --version`과 `node --version` 결과를 보여 줘.
4. `pip install`이나 `npm install`로 패키지를 설치할 수 있어?
5. GitHub 공개 저장소를 `git clone`할 수 있어?
6. 인터넷의 아무 사이트에나 접속할 수 있어, 아니면 막힌 도메인이 있어?
7. 네가 만든 파일은 다음 작업, 다음 날, 재부팅 뒤에도 남아 있어? 파일을 주로 어디에 저장해?

## B. 브라우저와 웹
8. 내가 준 URL(예: 직접 만든 웹 페이지)에 접속해서 입력창에 글을 쓰고, 버튼을 누르고, 결과를 읽을 수 있어?
9. 브라우저 화면을 거치지 않고 HTTP 요청(curl, fetch 등)을 보낼 수 있어? JSON 응답을 읽을 수 있어?
10. 로그인이 필요 없는 페이지라면 사람의 도움 없이 혼자 끝까지 쓸 수 있어?

## C. 스킬, 지침, 루틴
11. 스킬(재사용 절차)은 어떤 형식으로 정의돼? 파일이라면 경로와 형식(마크다운 구조, 필수 항목)을 알려 줘.
12. 내가 스킬 파일이나 지침 텍스트를 주면 그걸 등록해서 계속 따를 수 있어? 방법을 알려 줘.
13. "모든 작업을 시작하기 전에 항상 X를 하라" 같은 규칙을 매번 빠짐없이 지키게 할 수 있어? 어디에 적어야 해?
14. 루틴은 어떻게 만들어? 정해진 시각에 실행하기, 특정 메시지가 오면 실행하기가 가능해? 루틴 정의 형식도 알려 줘.
15. teach-a-task(시연해서 루틴 만들기)는 어떻게 써?

## D. 작업 시간 기록
16. 작업마다 시작 시각과 끝난 시각을 정확히 알 수 있어? 현재 시각을 확인하는 방법이 뭐야?
17. 지금까지 한 작업의 이력(작업 내용, 걸린 시간)이 남아 있어? 있다면 최근 5개를 보여 줘.
18. 작업을 시작하기 전에 몇 분 걸릴지 스스로 추정할 수 있어? 추정한다면 어떤 근거로 해?
19. 작업 중 대기 시간(내 승인을 기다린 시간, 페이지 로딩 등)을 따로 구분해서 기록할 수 있어?

## E. 알림과 완료 신호
20. 작업이 끝나면 나한테 어떤 방법으로 알려 줘? (앱 알림, Slack, 이메일, 텔레그램 등)
21. 작업이 끝났을 때 내가 지정한 URL로 HTTP POST(webhook)를 보낼 수 있어?
22. 승인 요청이 생기면 그 사실을 앱 밖(Slack, 이메일, 내 서버 등)으로도 알릴 수 있어?
23. 네 전용 이메일 주소가 있어? 있다면 알려 줘. 그 주소로 작업을 받거나 결과를 보낼 수 있어?

## F. 외부 연동
24. 다른 프로그램이 너에게 작업을 넘기는 공식 방법(API, webhook, SDK)이 있어?
25. 다른 프로그램이 네 작업 상태(진행 중, 끝남, 승인 대기)를 조회할 방법이 있어?
26. Slack이나 메신저 채널에서 멘션으로 작업을 받는 기능이 있어? 연결하려면 어떻게 해?
27. 다른 그록봇과 정보를 주고받을 수 있어? 어떤 방식이야?

## G. 제한
28. 동시에 몇 개의 작업을 할 수 있어?
29. 작업 하나에 실행 시간 제한이 있어?
30. 하루 사용량이나 요청 횟수 제한이 있어?
31. 하면 안 되거나 할 수 없는 일 중에 내가 알아야 할 게 있어?

마지막으로, 이 답변을 바탕으로 작업 시간 예측 도구를 "네 VM에 설치하는 프로그램"과 "네가 브라우저로 접속하는 웹 페이지" 중 어느 쪽으로 만드는 게 너한테 더 쓰기 편할지 이유와 함께 추천해 줘.
```
